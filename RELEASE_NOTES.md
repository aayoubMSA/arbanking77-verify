# ArBanking77-Verify v0.1.1 — Sanitized archival release

## Scope

v0.1.1 is a publication-hygiene update of v0.1.0.

No scientific result, comparison rule, normalization rule, source hash, or
frozen observable has changed.

## Changes from v0.1.0

- removes stale pre-publication status wording;
- removes internal work-package/status language from public release notes;
- changes the historical profile scope wording from an unsupported
  organizer-distribution formulation to a participant-retained formulation;
- removes private/internal build-path provenance from `SOURCE_PROVENANCE.json`;
- updates software version metadata to `0.1.1`.

## Unchanged evidence and behavior

The source identities and frozen historical/current comparison remain:

- exact: shared 11,110; historical unmatched 611; current-only 850;
- NFKC + whitespace: shared 11,180; historical unmatched 541; current-only 780;
- Arabic-light: shared 11,180; historical unmatched 541; current-only 780;
- Arabic-light + punctuation: shared 11,220; historical unmatched 501; current-only 740.

These are compatibility observables. They do not establish organizer intent,
leaderboard invalidity, dialect attribution of unmatched participant rows,
score impact, or correctness of unrecovered gold data.

## Redistribution boundary

The package contains software, profiles, tests, metadata, and documentation
only. It does not redistribute ArBanking77 datasets, participant task archives,
model weights, non-public research materials, authentication material, or
restricted research material.

## Lineage

v0.1.0 remains the historical first archival release.
v0.1.1 supersedes it for manuscript citation and publication use because its public
metadata and provenance wording are publication-clean.
